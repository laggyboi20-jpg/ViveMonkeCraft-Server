# ViveMonkeCraft Server

ViveMonkeCraft Server is a companion server side mod for ViveMonkeCraft. It helps server owners manage and control client side movement features while keeping gameplay fair for everyone.

## Features

### Server Side Configuration
Server administrators can configure and limit player movement settings from the server side. This allows servers to decide which features are allowed and prevent settings from creating unfair advantages.

### Client Setting Control
Client side options can be restricted by the server. Players can still use supported features, but within the limits chosen by the server owner.

### Fair Multiplayer Gameplay
Designed for VR and movement based gameplay, the mod helps keep player abilities consistent across a server by making sure important settings follow server rules.
